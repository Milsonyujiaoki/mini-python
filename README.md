# mini-python

Rebuilding the Python ecosystem from scratch for deep learning in:

- language internals
- data structures
- networking
- concurrency
- databases
- interpreters
- scientific computing
- web frameworks
- runtime systems

## Goals

This project aims to understand how modern software abstractions work internally by recreating:

- itertools
- functools
- collections
- requests
- asyncio
- ORM systems
- NumPy-like arrays
- interpreters and virtual machines
